# Terraform Azure DevSecOps

This repository demonstrates Infrastructure as Code (IaC) using Terraform on Microsoft Azure.

## Project Goals

- Learn Terraform from scratch
- Build reusable Terraform modules
- Implement Azure infrastructure
- Follow Git branching strategy
- Implement CI/CD using GitHub Actions
- Follow DevSecOps best practices
